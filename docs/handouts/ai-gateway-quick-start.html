For lab members

Collect your key and start using it

1. Collect your key

Open the claim link from your PI, sign in with your UCR NetID account, accept the terms and click Show my key. It is shown once: copy it straight into an environment variable, not your code.

$ export UCR_AI_GATEWAY_KEY=your-key # add to ~/.zshrc or ~/.bashrc

2. Use it (OpenAI-compatible)

Base URL for Python, OpenCode and most tools:

https://ucr-ursa-major-ai-gateway-service-575977597413.us-central1.run.app/v1

Python · pip install openai

from openai import OpenAI; import os client = OpenAI(base_url="<base URL above>", api_key=os.environ["UCR_AI_GATEWAY_KEY"]) r = client.chat.completions.create(model="gemini-3.8-flash", messages=[{"role": "user", "content": "hello"}]) print(r.choices[0].message.content)

Model choice is the biggest cost lever. A Claude agent session can spend tens of dollars an hour.

Rules of the road

  • P1 and P2 data only. No student records, health information, ID or account numbers, export-controlled data or CUI without written ISO approval.
  • Your key is yours. Never in code, a repo, chat, email or a shared file. Never shared.
  • Leaked? Report it at once: it is blocked immediately. Email research-computing@ucr.edu.
  • UCR work only, under UC policy (Electronic Communications Policy, IS-3).
  • A pilot. Allowances, models and terms can change.

What the gateway sees

Who, which model, tokens and cost, so your PI can see spend. Not the text of your prompts or the answers. Requests are processed by Google Cloud (Vertex AI) on UCR's account.
